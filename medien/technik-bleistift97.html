Begriffe

Die CPU verarbeitet Daten. Hardware sind die sichtbaren Teile, Software sind Programme. Input sind Eingaben, Output sind Ausgaben. Daten liegen im Speicher.

Mini-Aufgabe: Input → Verarbeitung → Output

Eine mögliche Antwort

Beispiel Foto: Kamera nimmt Lichtdaten auf → CPU und Foto-App verarbeiten und speichern die Bilddaten → Bildschirm zeigt das Foto. Die Kamera ist Eingabe, die Verarbeitung erfolgt im Gerät, die sichtbare Anzeige ist Ausgabe.

Reflexion

Meine Ergebnisse

Eine mögliche Antwort

Ich habe verstanden, dass Hardware die körperlichen Bauteile und Software die Programme bezeichnet. RAM hält Daten für gerade laufende Programme bereit, während SSD oder Flash Dateien dauerhaft speichern. Ein technisches System lässt sich als Eingabe, Verarbeitung und Ausgabe beschreiben. Noch üben möchte ich die Einordnung von Bauteilen, die mehrere Rollen erfüllen: Ein Touchscreen ist zugleich Anzeige und Eingabe.
