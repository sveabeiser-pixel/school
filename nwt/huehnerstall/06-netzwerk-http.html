6. WLAN, IP-Adresse und HTTP

Vier Ebenen im Projekt

WLAN ist die Funkverbindung. Eine IP-Adresse identifiziert ein Gerät im lokalen Netz. TCP sorgt typischerweise für zuverlässige Übertragung. HTTP beschreibt die Anfrage und Antwort zwischen Client und Server.

Client

Der Browser fragt eine Ressource an.

Server

Der ESP32 empfängt die Anfrage und liefert HTML oder Daten zurück.

„Der ESP32 hat WLAN“ bedeutet deshalb noch nicht, dass jede Webseite aus dem Internet erreichbar ist. Lokale Adressen und Zugriffsrechte bleiben wichtig.

Netzwerkdiagnose

Wenn eine Seite nicht erreichbar ist, prüfst du Stromversorgung, WLAN-Verbindung, IP-Adresse, Erreichbarkeit im selben Netz, Serverroute und erst danach den HTML-Inhalt.
