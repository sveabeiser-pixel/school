3. Temperatur und relative Luftfeuchtigkeit

Der KY-015 liefert digitale Messwerte - aber kein vollständiges Stallklima.

Was wird gemessen?

Temperatur wird über ein temperaturabhängiges Sensorelement erfasst. Die relative Luftfeuchtigkeit beschreibt, wie stark die Luft im Verhältnis zur maximal möglichen Wasserdampfmenge bei dieser Temperatur mit Wasserdampf beladen ist. Sie wird in Prozent relativer Feuchte (%RH) angegeben.

Wichtig für die Interpretation

Warme Luft kann mehr Wasserdampf aufnehmen als kalte Luft. Ein gleichbleibender Wasserdampfgehalt kann deshalb bei Temperaturänderung zu einer anderen relativen Feuchte führen.

Sensorwerte hängen von Messbereich, Genauigkeit, Reaktionszeit, Einbauort und Versorgung ab. Ein Lernmodul ist nicht automatisch ein kalibriertes Stallmessgerät.

KY-015 / DHT11 an den ESP32 anschließen

Beim Joy-it X40 verwendest du den KY-015. Das ist ein fertiges DHT11-Modul mit drei Anschlüssen. Das ist einfacher als ein nackter 4-Pin-DHT11, weil die Zusatzbeschaltung auf dem Modul bereits vorbereitet ist.

Verdrahtung am Joy-it NodeMCU ESP32

KY-015 / DHT11-ModulESP32Begründung
S / SignalGPIO 4Datenleitung; im Programm steht später dieselbe Pin-Nummer.
+ / VCC3V3Das Modul wird mit 3,3 V betrieben, damit auch das Datensignal ESP32-tauglich bleibt.
- / GNDGNDGemeinsame Masse ist nötig, damit Signalpegel eindeutig sind.

GPIO 4 ist nicht zwingend. Du kannst viele andere geeignete GPIOs verwenden. Entscheidend ist: Der Pin im Aufbau und die Pin-Nummer im Programm müssen übereinstimmen.

Stopp vor dem Upload:

Betreibe das Modul am ESP32 mit 3,3 V, nicht mit 5 V. Ein 5-V-Datensignal kann einen 3,3-V-GPIO beschädigen oder zumindest unzuverlässig machen.

Bibliothek installieren und ersten Messwert lesen

Die DHT-Sensoren haben ein eigenes digitales Zeitprotokoll. Du schreibst dieses Protokoll nicht selbst, sondern nutzt eine Bibliothek.

Bibliothek in der Arduino IDE

  1. Öffne Sketch → Bibliothek einbinden → Bibliotheken verwalten.
  2. Suche nach DHT sensor library.
  3. Installiere DHT sensor library by Adafruit.
  4. Wenn die IDE nach Adafruit Unified Sensor fragt, installiere diese Bibliothek ebenfalls.

Einfachstes Testprogramm

#include <DHT.h>

#define DHTPIN 4
#define DHTTYPE DHT11

DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(115200);
  dht.begin();
}

void loop() {
  float temperatur = dht.readTemperature();
  float luftfeuchtigkeit = dht.readHumidity();

  Serial.print("Temperatur: ");
  Serial.print(temperatur);
  Serial.println(" °C");

  Serial.print("Luftfeuchtigkeit: ");
  Serial.print(luftfeuchtigkeit);
  Serial.println(" %");

  Serial.println("----------------");

  delay(2000);
}

Öffne danach den seriellen Monitor und stelle ihn auf 115200 Baud. Du solltest ungefähr solche Ausgaben sehen:

Temperatur: 21.0 °C
Luftfeuchtigkeit: 53.0 %
----------------

Was passiert im Programm?

Der Sketch besteht aus wenigen wichtigen Bausteinen. Wenn du diese Bausteine verstehst, kannst du später selbst entscheiden, wann der Stall zu warm oder zu feucht ist.

Die wichtigsten Zeilen

CodezeileBedeutung
#include <DHT.h>Bindet die DHT-Bibliothek ein.
#define DHTPIN 4Legt fest, dass die Datenleitung an GPIO 4 hängt.
#define DHTTYPE DHT11Legt den Sensortyp fest.

float bedeutet, dass die Variable eine Gleitkommazahl speichern kann, zum Beispiel 21.0 oder 53.5.

Aus Messwerten wird Steuerung

if (temperatur > 30) {
  Serial.println("Zu warm!");
}

Damit passiert der entscheidende Schritt: Der ESP32 liest nicht nur Werte, sondern bewertet sie. Genau daraus entstehen später Regeln für Warnungen, Lüftung oder Anzeige auf der Webseite.

Sinnvolle Fehlerprüfung

Ein Sensor liefert nicht immer einen gültigen Wert. Kabel können locker sein, der Pin kann falsch sein oder die Abfrage kann fehlschlagen. Für ein Projektprogramm prüfst du deshalb, ob die Werte gültig sind.

#include <DHT.h>

#define DHTPIN 4
#define DHTTYPE DHT11

DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(115200);
  dht.begin();
}

void loop() {
  float temperatur = dht.readTemperature();
  float luftfeuchtigkeit = dht.readHumidity();

  if (isnan(temperatur) || isnan(luftfeuchtigkeit)) {
    Serial.println("Fehler beim Auslesen des DHT11!");
    delay(2000);
    return;
  }

  Serial.print("Temperatur: ");
  Serial.print(temperatur);
  Serial.println(" °C");

  Serial.print("Luftfeuchtigkeit: ");
  Serial.print(luftfeuchtigkeit);
  Serial.println(" %");

  delay(2000);
}

isnan(...) prüft, ob ein Messwert keine gültige Zahl ist. Wenn die Fehlermeldung erscheint, prüfst du zuerst 3V3, GND, Signalpin und ob im Code wirklich GPIO 4 steht.

Messreihe, Plausibilität und Unterrichtsaufgabe

Nehmt mehrere Messwerte in gleichen Zeitabständen auf. Notiert Uhrzeit, Temperatur, %RH, Einbauort und besondere Ereignisse wie geöffnete Fenster oder Berührung des Sensors.

Typische Fehler

  • Der Sensor wird zu schnell hintereinander abgefragt.
  • Der Datenpin ist falsch oder die Versorgung passt nicht zur Modulvariante.
  • Ein einzelner Wert wird als sichere Wahrheit behandelt.
  • Der Sensor liegt direkt an einer Wärmequelle oder im Luftstrom.

Aufgabe im Unterricht

Starte zunächst nur mit der Temperaturausgabe. Wenn das funktioniert, ergänze selbstständig die Luftfeuchtigkeit mit readHumidity(). Dadurch wird die Aufgabe zu einer kleinen Programmierleistung statt reinem Abschreiben.
