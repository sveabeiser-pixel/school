1) Welche Aussagen zu Motoren sind richtig?

Motoren erzeugen Bewegung; Motoren benötigen oft mehr Strom; Motoren brauchen Schutzbeschaltung

Motoren erzeugen Bewegung, brauchen Strom und oft Schutzbeschaltung.

2) Wozu dient PWM bei Motoren?

Steuerung der Geschwindigkeit; Veränderung der mittleren Leistung

PWM verändert die mittlere Leistung und damit oft die Geschwindigkeit des Motors.

3) Welche Bauteile werden häufig zur Motorsteuerung genutzt?

Transistor; Motortreiber-Modul; Freilaufdiode

Transistor, Motortreiber und Freilaufdiode sind typische Bauteile in Motor-Schaltungen.

Mini-Challenge: Ventilator steuern

Plan für den geprüften L298N-Aufbau: IN1 an D3, IN2 an D4, ENA an D5 ohne ENA-Jumper. Taster zwischen D2 und GND, INPUT_PULLUP: gedrückt bedeutet LOW. Die Geschwindigkeit steigt beim Gedrückthalten begrenzt an; Loslassen setzt ENA auf 0 und lässt den Motor auslaufen. Aufbaukontrolle, passende externe Motorversorgung und gemeinsame Masse gehören dazu.

const int IN1 = 3, IN2 = 4, ENA = 5, TASTER = 2;
int geschwindigkeit = 0;
void setup() {
  pinMode(IN1, OUTPUT); pinMode(IN2, OUTPUT);
  pinMode(ENA, OUTPUT); pinMode(TASTER, INPUT_PULLUP);
  digitalWrite(ENA, LOW);
  digitalWrite(IN1, HIGH); digitalWrite(IN2, LOW);
}
void loop() {
  if (digitalRead(TASTER) == LOW) {
    geschwindigkeit = min(geschwindigkeit + 5, 200);
  } else {
    geschwindigkeit = 0;
  }
  analogWrite(ENA, geschwindigkeit);
  delay(20);
}

Bei kleinen PWM-Werten kann der Motor noch stehen. Die Regelung legt keine exakte Drehzahl fest und ist kein Ein/Aus-Umschalter mit Zustandswechsel pro Tastendruck.

L298N: Steuerung und Motorversorgung trennen

Verständnisfragen - L298N

Eine mögliche Antwort
  1. Die H-Brücke kehrt die Spannungspolung am Gleichstrommotor um und ermöglicht damit beide Drehrichtungen. Mit der passenden Ansteuerung sind auch Abschalten und Bremsen möglich.
  2. VS ist die Motorversorgung, VSS die Logikversorgung und GND der gemeinsame Bezugspunkt. Die genaue Verdrahtung hängt vom Modul und seiner Jumper-/Reglerkonfiguration ab.
  3. Der Treiber setzt wegen seiner Spannungsabfälle Leistung in Wärme um. Ein geeigneter Kühlkörper hilft, Überhitzung zu vermeiden; Motor- und Logikspannung müssen innerhalb der Modulgrenzen liegen und zum Motor passen.

Stopp & check

Weil die Motoren viel Leistung brauchen, während der Logikteil nur die Steuersignale verarbeitet. VS versorgt die Motorleistung, VSS die interne Logik. Beides muss zusammen mit GND sauber verdrahtet sein.

15.1 Ein Motor läuft und bremst

D3 → IN1, D4 → IN2, D5 → ENA ohne ENA-Jumper; Motor an OUT1/OUT2. Arduino-GND, Modul-GND und Minus der geeigneten Motorversorgung sind verbunden. VS versorgt den Motorzweig, VSS die 5-V-Logik über den geprüften Regler-/Jumperweg. Die konkrete Modulplatine besitzt passende Schutzdioden. Kein Motorstrom fließt aus einem Digitalpin; 5-V-Ausgänge werden nicht gegeneinander verbunden.

const int IN1 = 3, IN2 = 4, ENA = 5;
void setup() {
  pinMode(IN1, OUTPUT); pinMode(IN2, OUTPUT); pinMode(ENA, OUTPUT);
  digitalWrite(ENA, LOW);
}
void loop() {
  digitalWrite(IN1, HIGH); digitalWrite(IN2, LOW);
  digitalWrite(ENA, HIGH); delay(2000);
  digitalWrite(IN2, HIGH); delay(2000);
  digitalWrite(ENA, LOW);
}

Zwei Sekunden Richtung 1, dann zwei Sekunden elektrisches Bremsen mit beiden Eingängen HIGH. Vertauschte IN1/IN2-Pegel kehren die Richtung um. ENA LOW bedeutet dagegen Auslaufen. Bleibt der Motor stehen, sind ENA-Freigabe, Versorgung und gemeinsame Masse erste Prüfpunkte; eine tatsächliche Beobachtung ist am eigenen Aufbau zu dokumentieren.

15.2 Zwei Motoren mit Funktionen steuern

Zusätzlich: IN3 an D7, IN4 an D8, ENB an D6 ohne ENB-Jumper; Motor B an OUT3/OUT4. Hier gilt Motor A = links, B = rechts. Bei der Montage wird vorher geprüft, welche Polung beide Räder am Modell tatsächlich vorwärts bewegt. Folgendes Beispiel nimmt HIGH/LOW für beide Vorwärtsrichtungen an.

const int IN1 = 3, IN2 = 4, ENA = 5;
const int IN3 = 7, IN4 = 8, ENB = 6;
void setup() {
  pinMode(IN1, OUTPUT); pinMode(IN2, OUTPUT); pinMode(ENA, OUTPUT);
  pinMode(IN3, OUTPUT); pinMode(IN4, OUTPUT); pinMode(ENB, OUTPUT);
  digitalWrite(ENA, LOW); digitalWrite(ENB, LOW);
}
void stopp() {
  digitalWrite(ENA, LOW); digitalWrite(ENB, LOW);
}
void beideVorwaerts() {
  digitalWrite(IN1, HIGH); digitalWrite(IN2, LOW);
  digitalWrite(IN3, HIGH); digitalWrite(IN4, LOW);
  digitalWrite(ENA, HIGH); digitalWrite(ENB, HIGH);
}
void beideRueckwaerts() {
  digitalWrite(IN1, LOW); digitalWrite(IN2, HIGH);
  digitalWrite(IN3, LOW); digitalWrite(IN4, HIGH);
  digitalWrite(ENA, HIGH); digitalWrite(ENB, HIGH);
}
void linksVorwaerts() {
  stopp();
  digitalWrite(IN1, HIGH); digitalWrite(IN2, LOW);
  digitalWrite(ENA, HIGH);
}
void rechtsVorwaerts() {
  stopp();
  digitalWrite(IN3, HIGH); digitalWrite(IN4, LOW);
  digitalWrite(ENB, HIGH);
}
void loop() {
  beideVorwaerts(); delay(1000); stopp(); delay(2000);
  beideRueckwaerts(); delay(1000); stopp(); delay(2000);
  linksVorwaerts(); delay(1000); stopp(); delay(2000);
  rechtsVorwaerts(); delay(1000); stopp(); delay(2000);
}

Die Pausen müssen lang genug sein, dass die frei drehenden Räder vor einem Richtungswechsel stillstehen. Bei spiegelverkehrter Montage ist gegebenenfalls eine Motorpolung beziehungsweise ihre Richtungszuordnung anzupassen, immer bei getrennten Versorgungen.

Schrittmotor: In 3 Schritten zum ersten Aufbau

Stopp & check

Weil die Spulen des Motors in einer festen Reihenfolge angesteuert werden müssen. Wenn die Reihenfolge nicht stimmt, ruckelt der Motor, läuft gar nicht oder dreht in einer unerwarteten Weise.

Bring den Ablauf in die richtige Reihenfolge

  1. Bei getrennten Versorgungen den Motor an die Treiberplatine stecken
  2. IN1 bis IN4 mit den Pins 3, 4, 5 und 6 verbinden
  3. Separate 5-V-Motorversorgung stromlos verdrahten und ihre Masse mit Treiber und Arduino verbinden
  4. Arduino per USB anschließen und Port wählen
  5. Sketch prüfen und hochladen; nach Aufbaukontrolle Motorversorgung einschalten und kurz testen

Sicherung: Wichtige Begriffe einsetzen

In der Arduino-IDE musst du zuerst den richtigen Port auswählen. Die Bibliothek Stepper.h stellt Funktionen für den Motor bereit. Der Code in setup() läuft nur einmal beim Start, der Code in loop() wiederholt sich ständig. Im Beispiel wird eine volle Umdrehung näherungsweise mit 2048 Schritten angesetzt.

Wahr oder falsch?

Wahr. Wenn in step() eine negative Schrittzahl steht, bewegt sich der Schrittmotor in die andere Richtung.

Genau so ist es: Das Vorzeichen entscheidet über die Drehrichtung, die absolute Zahl über die Anzahl der Schritte.

Transfer: Verändere den Sketch gedanklich

Eine mögliche Antwort

Im Beispiel entsprechen 2048 Schritte einer Umdrehung. Für eine halbe Umdrehung verwende ich daher 1024 Schritte vorwärts und -1024 Schritte zurück. Vor der Vorwärtsbewegung stelle ich setSpeed(5) ein. Vor der Rückbewegung kann ich beispielsweise setSpeed(10) verwenden, sofern der Motor diese Geschwindigkeit unter der Last zuverlässig erreicht. Anschließend muss ich vor der nächsten Vorwärtsbewegung wieder auf 5 Umdrehungen pro Minute zurückstellen. Die Schrittzahl des Motorobjekts bleibt 2048, weil sich seine Schritte pro voller Umdrehung nicht ändern.

void loop() {
  Schrittmotor.setSpeed(5);
  Schrittmotor.step(1024); delay(1000);
  Schrittmotor.setSpeed(10);
  Schrittmotor.step(-1024); delay(1000);
}

Schrittmotor: eine Umdrehung hin und zurück

Für das Beispiel 5-V-28BYJ-48 mit passender ULN2003-Platine: IN1 → D3, IN2 → D4, IN3 → D5, IN4 → D6. Motorversorgung extern geregelt mit 5 V an der Treiberplatine; ihr Minus, Treiber-GND und Arduino-GND sind verbunden. Externes Plus bleibt vom Arduino-5V getrennt. Die Bibliotheksreihenfolge IN1, IN3, IN2, IN4 ergibt die Konstruktorpins 3, 5, 4, 6.

#include <Stepper.h>
int steps = 2048;
Stepper Schrittmotor(steps, 3, 5, 4, 6);
void setup() { Schrittmotor.setSpeed(5); }
void loop() {
  Schrittmotor.step(2048); delay(1000);
  Schrittmotor.step(-2048); delay(1000);
}

Mit dem Näherungswert 2048 und 5 Umdrehungen pro Minute dauert jede Drehung ungefähr 12 s, danach folgt jeweils 1 s Pause. Der Zyklus dauert ungefähr 26 s. Ohne Schrittverluste kehrt die Welle ungefähr zur Markierung zurück; reale Getriebeübersetzung und Spiel begrenzen die Genauigkeit. Bei Brummen wird stromlos zuerst die Pinfolge geprüft. Spulen können im Stillstand bestromt bleiben; nach dem kurzen Versuch wird die Motorversorgung abgeschaltet.

Mini-Check: Servos

1) Welche Aussage trifft auf einen Standard-Servo zu?

Er kann gezielt auf bestimmte Winkel eingestellt werden.

Ein Standard-Servo wird auf Winkelstellungen eingestellt und dreht sich nicht endlos weiter.

2) Welche Leitungen gehören typisch zu einem Servo?

5V; GND; Signal

Ein Servo hat typischerweise Versorgung, Masse und eine Signalleitung.

Fehler finden

Ein Digitalpin liefert nur das Steuersignal, nicht den Motorstrom. Wir verwenden eine zum Servo passende externe Versorgung und verbinden deren Minus mit Servo-GND und Arduino-GND. Nennspannung, Anlaufstrom und mechanischer Winkelbereich müssen zum konkreten Servo passen.

Servo: zwei Winkel anfahren

Beim freigegebenen 5-V-Positionsservo führt das Signal zu D9. Eine passende externe Versorgung liefert den Motorstrom; ihr Minus, Servo-GND und Arduino-GND sind verbunden. Externes Plus wird nicht mit Arduino-5V verbunden. Belegung und Winkelbereich werden am konkreten Bauteil geprüft.

#include <Servo.h>
Servo S1;
void setup() { S1.attach(9); }
void loop() {
  S1.write(30); delay(1000);
  S1.write(90); delay(1000);
}

Das Objekt S1 wird an den Signalpin gebunden; write() übermittelt eine Zielstellung und keine Bestätigung der tatsächlichen Ankunft. Bei erfolgreichem Test wechselt der unbelastete Servo ungefähr zwischen 30° und 90°. Ändere ich 30 auf 60, verringert sich der angeforderte Winkelunterschied von 60° auf 30°; die Wartezeiten bleiben gleich. Die tatsächlichen Winkel können abweichen. Bei Anschlag, Wärme oder anhaltendem Brummen wird abgeschaltet.

DC-Motoren: schnell, einfach, aber weniger präzise

Wahr oder falsch?

Falsch. Ein einfacher DC-Motor ist ohne zusätzliche Sensorik sofort die beste Wahl, wenn du einen Arm exakt auf 45° stellen willst.

Für eine exakte Winkelposition ist ein Standard-DC-Motor allein ungeeignet. Ein Servo oder ein Schrittmotor passt hier meist besser.

Für die Schranke wähle ich einen Servo, weil ein definierter Öffnungswinkel benötigt wird. Seine Regelung hält die angeforderte Stellung innerhalb der mechanischen Möglichkeiten. DC-Motor: Richtung und Drehzahl getrennt steuern

Der unveränderte L298N-Aufbau aus 15.1 bleibt bestehen. PWM liegt an ENA/D5, Richtung an IN1/D3 und IN2/D4; der Motor liegt an den Treiberausgängen. Eine Diode allein erlaubt keinen direkten Motorbetrieb an Arduino-Pins.

const int motorPin1 = 3, motorPin2 = 4, enablePin = 5;
void setup() {
  pinMode(motorPin1, OUTPUT); pinMode(motorPin2, OUTPUT);
  pinMode(enablePin, OUTPUT); digitalWrite(enablePin, LOW);
}
void motorStop() { analogWrite(enablePin, 0); delay(1000); }
void loop() {
  motorStop();
  digitalWrite(motorPin1, HIGH); digitalWrite(motorPin2, LOW);
  analogWrite(enablePin, 180); delay(1000);
  motorStop();
  digitalWrite(motorPin1, LOW); digitalWrite(motorPin2, HIGH);
  analogWrite(enablePin, 180); delay(1000);
  motorStop();
  digitalWrite(motorPin1, LOW); digitalWrite(motorPin2, HIGH);
  for (int i = 0; i <= 200; i++) {
    analogWrite(enablePin, i); delay(20);
  }
  motorStop();
}

Zeitlinie idealisiert: 0–1 s auslaufen, 1–2 s Richtung 1 mit PWM 180, 2–3 s auslaufen, 3–4 s Gegenrichtung mit 180, 4–5 s auslaufen, 5–9,02 s Rampe in Gegenrichtung, 9,02–10,02 s auslaufen. Danach folgt beim nächsten loop()-Start erneut motorStop(), also eine weitere Sekunde Pause. Die Rampe enthält 201 Werte von 0 bis 200. 20 auf 40 ms verdoppelt ihre Dauer von ungefähr 4,02 auf 8,04 s, nicht den Endwert. 180 auf 140 verringert das Tastverhältnis; eine niedrigere Drehzahl ist unter gleichen Bedingungen plausibel, aber keine exakt proportionale oder bei jeder Last garantierte Wirkung. Eigene Beobachtungen und eine gezielte Fehlerprüfung werden am realen Aufbau dokumentiert.
